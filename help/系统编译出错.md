# 系统编译出错记录

> 记录泰山派 SDK（Buildroot）编译时遇到的两类问题：依赖不全、PATH 里有空格。
> 环境：Ubuntu 22.04（WSL2）

## 一、先排除依赖问题

编译过程中如果出现"未知错误、什么也没输出"，**先检查编译工具是否装全**。
有些依赖缺失会明确提示缺哪个包，有些则不会——后者最容易让人卡住。

一次性装齐（官方要求的依赖清单）：

```bash
sudo apt-get install git ssh make gcc libssl-dev liblz4-tool expect \
g++ patchelf chrpath gawk texinfo chrpath diffstat binfmt-support \
qemu-user-static live-build bison flex fakeroot cmake gcc-multilib \
g++-multilib unzip device-tree-compiler ncurses-dev
```

装完重试，如果还是同样的错，再看下一节。

## 二、PATH 里含空格导致的失败

### 关键报错

```
Your PATH contains spaces, TABs, and/or newline (\n) characters.
This doesn't work. Fix you PATH.
make: *** [support/dependencies/dependencies.mk:27: dependencies] Error 1
```

### 原因

Windows 下的程序路径经常带空格（例如 `Program Files`）。Linux 本身允许 PATH 条目含空格，但 **Buildroot 的依赖检查会直接拒绝**这种情况。

WSL 里一旦把 Windows 的路径混进 `PATH`，就会触发这个报错。

### 解决

**第 1 步：确认是哪些目录带空格**

```bash
python3 -c 'import os; print([repr(p) for p in os.environ["PATH"].split(":") if any(c.isspace() for c in p)])'
```

输出里会列出所有含空白字符的 PATH 条目；如果输出 `[]`，说明 PATH 本身没问题，得往别处查。

**第 2 步：临时清理 PATH，再构建**

```bash
export PATH="$(python3 -c 'import os; print(":".join(p for p in os.environ["PATH"].split(":") if p and not any(c.isspace() for c in p)))')"
```

这条命令只删掉**当前 PATH 中**含空白字符的目录：

- 只影响当前终端会话
- 不删除任何文件
- 不永久修改系统配置

**第 3 步：验证**

```bash
python3 -c 'import os; print([repr(p) for p in os.environ["PATH"].split(":") if any(c.isspace() for c in p)])'
```

输出 `[]` 即通过。

**第 4 步：重新构建**

```bash
cd ~/workspace/main
./build.sh
```

如果 SDK 的完整构建命令是 `./build.sh all`，就沿用原来触发失败的那条命令。

## 三、备注

- PATH 的修改只在当前终端有效，**新开一个终端就要重新执行**。
- 想一劳永逸，应该在 `~/.bashrc` 里避免把 Windows 路径加进 `PATH`（WSL 默认会自动追加部分 Windows 路径，可用 `/etc/wsl.conf` 的 `appendWindowsPath=false` 关掉）。
