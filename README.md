## 记录约定

- 文件名用 `NN主题`，**一个文件一个主题**，按操作顺序编号。
- 命令一律放代码块并标语言（`bash` / `powershell`），方便直接复制。
- 截图放在同级目录，用 `![说明](文件名.png)` 引用，文件名不要带空格。
- 踩坑记录统一放 `help/`，按 **现象 → 排查 → 原因 → 解决** 四段写，只记实际验证过的结论。
