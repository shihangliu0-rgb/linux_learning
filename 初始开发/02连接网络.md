# 02 连接网络

> 目标：板子开机后连上网络，为后面的 SSH 远程开发和系统编译做准备。
> 前提：已完成 [01 下载镜像](01下载镜像.md)，系统能正常启动。

板子默认只有命令行，没有图形化的网络设置，WiFi 需要用 `wpa_supplicant` 手动连。

## 1. Windows 侧：查本机 IP

板子和电脑要处在同一网段，先在 Windows 上看本机地址：

```powershell
ipconfig
```

记下当前在用网卡的 IPv4 地址（例如 `192.168.1.23`），后面 SSH 连接要用。

## 2. 板卡侧：连 WiFi

三条命令，按顺序执行：

```bash
# 1) 生成 WiFi 配置，SSID 和密码换成自己的
wpa_passphrase "你的WiFi名称" "你的WiFi密码" > /tmp/wpa.conf

# 2) 后台启动 wpa_supplicant，绑定无线网卡 wlan0
wpa_supplicant -B -i wlan0 -c /tmp/wpa.conf

# 3) 向路由器申请 IP（动态获取）
udhcpc -i wlan0
```

## 3. 验证

```bash
ip addr show wlan0          # 能看到 inet 地址就说明拿到 IP 了
ping -c 4 www.baidu.com     # 能通说明外网正常
```

## 4. 注意：`/tmp` 是临时的

配置写进 `/tmp/wpa.conf`，重启就没了。想开机自动联网，需要：

1. 把配置放到 `/etc/` 下（例如 `/etc/wpa_supplicant.conf`）；
2. 在开机启动脚本里加上 `wpa_supplicant` 和 `udhcpc` 两条命令。

## 5. 下一步：SSH

网络通了就能在 Windows 上远程登录：

```bash
ssh 用户名@板卡IP
```

用户名和密码需要先在板子上确认/设置好（默认可能不是 root），否则会进不去。详见 [03 SSH 连接远程开发](03ssh连接远程开发.md)。
